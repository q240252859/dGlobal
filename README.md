# Decode Global

A Flutter application for Decode Global Exchange - Flash Transaction for Institutional Accounts.

## Features

- Login and user authentication
- Market listings with real-time updates
- Position tracking (current and history)
- Trading interface with charts
- Financial news feed
- Account management

## Getting Started

### Prerequisites

- Flutter SDK (3.0.0 or higher)
- Dart SDK (3.0.0 or higher)
- Android Studio / VS Code

### Installation

1. Clone the repository
```
git clone https://github.com/yourusername/decode-global.git
```

2. Navigate to project directory
```
cd decode-global
```

3. Install dependencies
```
flutter pub get
```

4. Run the app
```
flutter run
```

## Technical Framework

- **Language**: Flutter
- **Platform Support**: iOS, Android, H5
- **Key Dependencies**:
  - dio: Network requests
  - intl: Multilingual support
  - provider: State management
  - flutter_screenutil: Screen adaptation
  - pull_to_refresh_notification: Pull-to-refresh functionality
  - internet_connection_checker_plus: Network status monitoring
  - shared_preferences: Local storage
  - flutter_native_splash: Splash screen
  - cached_network_image: Image caching
